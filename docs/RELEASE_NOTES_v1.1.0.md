# TR4CEPIL0T v1.1.0

TR4CEPIL0T now runs on every landscape EdgeTX colour radio, not only the TX15.

## Which pack?
| Pack | Radios |
|---|---|
| `TR4CEPIL0T_TX15.zip` | RadioMaster TX15 / TX15 Max (optimised, with gimbal LED effects) |
| `TR4CEPIL0T_EdgeTX_480x320.zip` | RadioMaster GX15, Jumper T15 / T15 Pro / T15-H7 / T22, Flysky PL18 / PL18EV / PL18U / ST16 |
| `TR4CEPIL0T_EdgeTX_480x272.zip` | RadioMaster TX16S / MkII, HelloRadioSky V15 / V16, Jumper T16 / T18 / T18H7, FrSky X10 / X12S, iFlight Commando 14, Fatfish F16, Senduwing H17 |
| `TR4CEPIL0T_EdgeTX_320x240.zip` | Flysky PA01, HelloRadioSky V12 |
| `TR4CEPIL0T_EdgeTX_800x480.zip` | RadioMaster TX16S MK3 |

## What's new
- Page 2 reads the radio's switches and how many positions each one has; unused switches are hidden.
- More pots and sliders recognised; layout adapted to 480x272 and 800x480 screens.
- Splash and theme for each screen size.

Requires EdgeTX 2.11 or newer. The Global EdgeTX packs were checked on a PC simulation of each screen size;
reports from owners of these radios are very welcome in Issues.

If you enjoy it, you can support the project on [Ko-fi](https://ko-fi.com/tr4cepil0t). ☕
